# PC Executor

Актуализация каталога: 25 октября 2026 года.

Слой исполнения действий компьютерного агента на Windows. Содержит адаптеры окон, Windows UI Automation, снимков экрана, ввода, команд и восстановления действий.

## Что хранится в репозитории

- Ветка `main` хранит вводное описание.
- Реализации и проверки находятся в рабочих ветках репозитория; навигация — [все ветки](https://github.com/foto6/help-pc-1/branches).
- Прикладная политика и координация вынесены в `foto6/help-pc-2`; установленная интеграция описана отдельно в приватном каталоге владельца.

## С чего начать

Выбрать нужную рабочую ветку и следовать её README и файлам запуска. Главная ветка с вводным README сама по себе не описывает установленный экземпляр.

## Состояние

Существующие рабочие ветки сохранены. Каталогизация не изменяет правила исполнения или работающие процессы.

Изменения этого прохода относятся к описанию и сохранению существующей работы. Код продукта не дорабатывался.
